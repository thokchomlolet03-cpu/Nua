# Controlled safeguard comparison

Run date: 14 September 2026. This is a paired synthetic QA exercise, not a real-user study, learning experiment, accessibility audit, teacher validation or evidence of educational impact.

## Design

Six agents used one fixed mixed-understanding age-14 science persona per comparison. Each agent produced two 20-response arrays from the same frozen lesson: a current-presentation baseline and one safeguarded condition. Source, objective, question IDs and assessment criteria were held constant within each pair. The safeguard varied one setting only.

The actors were instructed not to create dramatic improvements and to preserve uncertainty where the underlying reasoning remained unresolved. This makes the comparison useful for workflow risk, but the generated pair is still not an independent controlled sample. The response text is synthetic and generated by the same model family.

## Results

| Safeguard | Baseline avg chars | Safeguarded avg chars | Baseline unsure / help | Safeguarded unsure / help | Leakage assessment |
|---|---:|---:|---:|---:|---|
| Response contracts | 234 | 269 | 5 / 1 | 3 / 0 | Low but nonzero: component list cues answer structure |
| Plain-language glossary | 211 | 248 | 6 / 0 | 1 / 0 | Low: meanings clarified, conclusions not supplied |
| Text-equivalent organiser | 284 | 336 | 6 / 1 | 1 / 1 | Low but nonzero: blank categories cue structure |
| Staged sessions | 257 | 233 | 4 / 1 | 2 / 1 | Low: no answer information added |
| Structured formats | 239 | 217 | 2 / 0 | 1 / 0 | Low: organization changed, reasoning criterion retained |
| Neutral help ladder | 189 | 215 | 5 / 2 | 0 / 0 | Highest risk: vary / hold equal / measure cues the framework |

“Unsur(e)” and “help” are synthetic self-reports. Average characters are a burden proxy, not active time or effort. The apparent reductions are descriptive outputs of one paired actor, not estimates of effect size.

## What is supported by this comparison

1. The six safeguards can be modelled without changing the underlying 20-question inventory.
2. All six paired fixtures contain 20 baseline and 20 safeguarded responses, with valid response lengths and signals.
3. Safeguards can change response organization and stated uncertainty without necessarily changing the source or question IDs.
4. Plain-language definitions appear most promising for reducing vocabulary-driven uncertainty in this synthetic run.
5. Staging and structured formats appear promising for reducing response-length burden in this synthetic run.
6. A neutral help structure may reduce explicit help requests while simultaneously providing more answer-relevant cues; fewer help requests is therefore not automatically a positive result.
7. The persistent misconception about repeated measurements versus causal isolation remains in the paired outputs, showing that access scaffolds do not automatically repair conceptual reasoning.

## What is not supported

The comparison does not establish improved learning, retention, focus, fairness, accessibility, real student completion, teacher workload, age suitability or assessment validity. It does not show that any safeguard is harmless for every learner. It does not show that shorter responses are better responses. It does not establish that the same actor would have produced the same baseline responses on a second run.

## Decision rules for a future system change

Do not accept a safeguard merely because it reduces uncertainty or help requests. A setting should proceed to implementation only if it:

- preserves the intended reasoning criterion;
- does not state or strongly cue the answer;
- reduces omitted required components or avoidable wording burden;
- accepts concise and equivalent language without lowering evidence requirements;
- preserves the distinction between access support and conceptual correction;
- can be represented in the learner and educator evidence record;
- remains compatible with all 20 inquiry types.

The immediate candidates for a bounded prototype test are the plain-language glossary, staged sessions and structured response formats. The text organiser needs an answer-cue review. The neutral help ladder requires adversarial testing because it may reveal the intended framework. Response contracts require testing that learners do not merely copy the listed components without reasoning.

## Required next tests

1. Give the same synthetic actors adversarial prompts and check whether each safeguard reveals the expected conclusion.
2. Use teacher-role reviewers to score baseline and safeguarded responses with a component rubric, blind to condition where possible.
3. Test contradictory, short, creative, additional-language and off-topic answers under every setting.
4. Compare criterion coverage, not only length, confidence or help requests.
5. Test a source with actual tables/diagrams and a source deliberately missing required evidence.
6. Test whether staging changes only navigation or also changes the reasoning expected from later questions.
7. Test whether structured formats accept equivalent evidence without privileging typing, grammar or diagram skill.

The system remains frozen after this comparison. These results identify candidates for a later controlled implementation pass; they do not authorize claiming that any safeguard improves education.
