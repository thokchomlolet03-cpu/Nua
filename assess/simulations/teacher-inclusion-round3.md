# Synthetic teacher-role inclusion and accessibility review — round 3

This is a synthetic teacher-role review by an inclusion/accessibility specialist. It is not a qualified educator review, an accessibility audit, educational validation, student research, or evidence about real learners. All findings, risks, suggested tests and safeguards below are synthetic.

## Synthetic inclusion bottom line

The central passage is compact, but access is not guaranteed by brevity. A learner must process a long sentence structure, causal vocabulary, multiple conditions and several distinctions between design, measurement and conclusion. The 20 prompts then repeat the same topic through increasingly abstract reasoning operations. A learner may therefore produce a short or incomplete answer because of language production, working-memory load, reading access, motor/typing access or uncertainty about the requested response form. That pattern must not be treated as evidence that the reasoning operation is absent.

The strongest low-scope safeguard is to make the response contract visible for each existing question: what to name, how many parts are needed, and which response modes are accepted. This does not add a feature or alter a criterion; it reduces avoidable access burden.

## Synthetic findings

### Compact answers are under-specified

Several prompts ask for two or more operations in one sentence. Examples include q1, q3, q5, q8, q12, q15, q16, q17, q18 and q20. “Short answer” is not defined in the frozen lesson. A learner may reasonably not know whether one sentence, a labelled table, a list or an explanation is expected.

Safeguard: display a compact response contract beside each prompt, using the existing criterion. For example, q18 can state: “Use three labels: vary, hold equal, measure. One item under each is enough to start.” Do not require a fixed sentence length, and do not penalise a correct answer for being shorter than a model response.

Synthetic test: give each prompt its response contract and compare completion, omitted subparts and unnecessary response length with the same prompt without the contract. Treat the result as synthetic usability evidence only.

### Additional-language phrasing creates avoidable barriers

The source and prompts use terms such as “isolate,” “relevant conditions,” “separate effects,” “counterfactual,” “causality,” “boundary,” “calibrated,” “criterion” and “interpretation.” Some are not necessary for the learner’s answer and may compete with the target reasoning. The passage also places several clauses in long sentences, including the sentence about light and fertilizer changing together.

Safeguard: provide a plain-language gloss at first use without replacing the original term. For example: “isolate an effect — make fertilizer the only planned difference,” and “evidence — information that supports or limits a claim.” Keep the scientific term available for later reuse. Permit equivalent everyday wording when it preserves the criterion.

Synthetic test: create a controlled prompt variant with the same content, the same number of required components and a small glossary. Check whether responses retain the target distinctions while showing fewer vocabulary-only clarification requests. Do not infer language ability or learning from this comparison.

### The passage has no diagram or visual relational structure

The lesson describes two designs in prose: a design where light and fertilizer both change, and a design where fertilizer changes while light and water remain equal. There is no visual representation of “varied,” “held equal,” “measured” and “repeated.” This places the relationship load on working memory, especially for q7–q9 and q16–q19.

Safeguard: offer an optional, text-equivalent organiser, not a new assessed object: two labelled columns for the two plant groups, rows for light, water, fertilizer and growth, and a separate “repeat” note. Use text labels and high-contrast patterns as well as colour; do not make colour the only distinction. The organiser must not supply an answer that the prompt asks the learner to construct.

Synthetic test: compare answers with and without the organiser, checking whether learners omit fewer roles or confuse design description with growth data. Also test the organiser in a text-only form so visual absence, colour vision and screen-reader access are not hidden variables.

### Cognitive load accumulates across the 20-question run

The one-page source is revisited through 20 distinct types. The repeated anchor is visibly truncated at “fertili” in each question object, while the full passage exists elsewhere in the lesson. A learner who relies on the nearby anchor may lose context or repeatedly reopen the source. Multi-part wording is especially demanding in q3, q8, q12, q15, q17, q18 and q20.

Safeguard: chunk the required questions into the round-2 three-session sequence, preserve q1–q20, and show one prompt at a time or in short labelled groups. Decompose only the display of a multi-part prompt into numbered parts; keep the original wording and type in the underlying record. Provide a stable source view or read-aloud option so memory of the passage is not the hidden task.

Synthetic test: record, per question, rereads, help requests, unfinished subparts and time-to-first-response under the staged display. Do not use these measures as ability scores. A missing response is “no evidence yet,” consistent with the round-2 safeguard.

### Response modalities need an explicit equivalence rule

The round-2 review appropriately proposes written answers, labelled tables, comparison diagrams, oral explanations and sentence frames. The frozen rubric does not state how a teacher should preserve the same criterion across modes. Typing, handwriting, speech, drawing and spelling can impose different burdens.

Safeguard: accept a short written answer, labelled table, accessible diagram, oral explanation transcribed by an adult, or speech-to-text output when the mode is available. Apply the same question-specific criterion to each. A diagram must label relationships; an oral answer must still include the required reasoning; a sentence frame must leave the claim for the learner to complete. Do not require disclosure of a disability or diagnosis to use an available mode.

Synthetic test: prepare equivalent response samples for each mode and check them against a mode-neutral checklist: changed factor, equal conditions, measurement, repetition, evidence limit or reasoning link, as applicable. Review disagreement cases manually; do not claim that mode equivalence has been validated.

### Help requests must distinguish access support from answer coaching

The frozen lesson has no visible help-request protocol. Without one, a learner may either abandon the item or request a full answer. The round-2 “A” code correctly warns that access difficulty must not be treated as absent reasoning, but it needs a bounded sequence.

Safeguard: use a three-step help ladder that does not reveal the target conclusion:

1. Rephrase the task in plain language or read it aloud.
2. Point to the relevant response contract or glossary entry.
3. Offer a neutral structure such as “vary / hold equal / measure,” then ask for a new attempt.

Record the help step used and whether the revised answer supplies the missing operation. Do not provide “fertilizer caused growth,” “light is the confounder,” or another answer-bearing cue as accessibility support.

Synthetic test: seed synthetic responses that are blank, vocabulary-confused, modality-blocked, partially correct and conceptually incorrect. Check that the ladder gives access support for the first two patterns, preserves the criterion, and escalates the latter patterns to reasoning follow-up rather than silently supplying an answer.

## Question-specific access checks

The following are synthetic checks, not predicted student diagnoses:

- q1–q2: verify that “define” and “reconstruct” do not require a particular wording; accept a labelled structure where all criterion parts are present.
- q3: make clear that the passage does not provide a biological mechanism for fertilizer absorption. Do not require invented biology; assess the comparison mechanism stated in the criterion.
- q4 and q15: visually distinguish “what the passage says” from “what measurements are absent,” because both can otherwise look like requests for a factual result.
- q5–q8: provide the same role labels in the organiser, but do not pre-classify them. Check that tables and lists are accepted.
- q9–q14: expose the conditional or hypothetical status of the prompt with a small marker such as “suppose” or “when,” without changing its claim or answer requirement.
- q10: preserve the conditional wording and do not imply that a fertilizer effect was observed.
- q12–q13 and q20: keep “tested plants/conditions” visible so bounded conclusions are not lost during transfer or counterexample reasoning.
- q16: accept a table description in words; the learner need not draw a table if the columns and limitation are stated.
- q17 and q19: use a two-part response contract so “list” is not mistaken for “explain the connection.”
- q18: define “fall time” in plain language if needed, while keeping the application type and the vary/hold-equal/measure criterion.

## Safeguards for synthetic review and reporting

- Label every fixture, response pattern, completion result and follow-up result “synthetic.”
- Do not describe synthetic response behaviour as learner, classroom or teacher evidence.
- Keep q1–q20 and their frozen types unchanged in any assessment comparison.
- Report access supports separately from reasoning outcomes; a revised answer after rephrasing is not directly comparable to an unsupported first attempt.
- Preserve a no-answer-support condition when testing whether the help ladder protects the criterion.
- Do not retain unnecessary personal or disability information in a synthetic tracker; use question ID, access support, missing operation and revised-response status.
- Treat blank, abandoned or unavailable-mode responses as “no evidence yet,” not incorrectness.
- Require a human review of any apparent mode-related disagreement before drawing a conclusion about the response.
- Stop a test if the organiser, glossary or help step reveals the answer rather than reducing access burden.

## Recommended synthetic test set before practical release

Run a small controlled round using the frozen q1–q20 set and synthetic response fixtures. Compare only the safeguards needed for this review:

1. original display versus compact response contracts;
2. original phrasing versus plain-language glosses;
3. prose-only source versus the optional text-equivalent organiser;
4. uninterrupted q1–q20 versus the staged sequence from round 2;
5. written-only collection versus the listed equivalent response modes;
6. no help ladder versus the three-step neutral help ladder.

For each comparison, report omitted subparts, clarification/help requests, response mode, rereads, abandonment and criterion coverage. Keep the report synthetic, avoid ranking learners, and do not call a lower burden “better learning” without educational validation. A safeguard passes this synthetic gate only if it reduces access burden without reducing criterion coverage or revealing the answer.

## Conclusion

Synthetic review finding: the lesson’s principal inclusion risk is not the number 20 by itself; it is the interaction between 20 required reasoning operations, dense multi-part language, absent relational visuals, repeated abstract terms and unspecified response/help conventions. The practical safeguards are bounded display changes, plain-language glosses, an optional text-equivalent organiser, equivalent response modes and a neutral help ladder. These recommendations preserve every 20+ type and require tests and safeguards rather than broad new features. They are not educational validation.
